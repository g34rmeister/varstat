VarStat for Windows (64-bit)
============================
1. Right-click the zip > Extract All.
2. Open the extracted folder and double-click VarStat.exe.
   If Windows SmartScreen appears, click "More info" > "Run anyway" (the app is not code-signed).
3. Optional: right-click VarStat.exe > Send to > Desktop (create shortcut).
